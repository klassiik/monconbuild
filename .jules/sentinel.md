## 2024-05-18 - XSS in JSON-LD Schema Injection
**Vulnerability:** A cross-site scripting (XSS) vulnerability was found across multiple frontend pages where JSON-LD schemas were injected directly into `<script>` tags using `{JSON.stringify(schema)}`. If user-controlled data within the schema contained a `</script>` string, it could break out of the script tag and execute arbitrary code.
**Learning:** `vite-react-ssg` correctly escapes double quotes when interpolating strings in JSX text children, but doesn't escape HTML tags securely.
**Prevention:** Always use `dangerouslySetInnerHTML={{ __html: JSON.stringify(schema).replace(/</g, '\\u003c') }}` when rendering dynamic JSON payloads inside `<script>` tags. The `\u003c` successfully encodes the `<` character to prevent early closure of the script block.
